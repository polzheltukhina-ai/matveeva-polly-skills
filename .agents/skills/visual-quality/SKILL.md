# Visual Quality

Apply root AGENTS.md. Check source color preservation, skin tones, typography hierarchy, contrast, restrained shadows/outlines, modern motion design, platform-specific safe zones, face clearance, audio continuity, and export integrity.

Do not impose a style that conflicts with the user's explicit brief. If safe-zone dimensions or platform UI details are uncertain, state the assumption and use conservative placement.
