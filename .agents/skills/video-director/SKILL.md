# Video Director

Use when the user asks to create, edit, plan, or adapt a video.

1. Read root AGENTS.md, SKILL-INDEX.md, and HOW-TO-CHOOSE.md.
2. Inspect actual files under .agents/skills; do not assume the index is current.
3. Analyze the user's brief and source media. Never invent unseen content or timestamps.
4. Select the smallest compatible set of skills and explain the selection.
5. Prepare a timecoded edit plan and storyboard.
6. Wait for approval before final rendering unless the user explicitly waives approval.
7. Execute, preview, quality-check, and export.
8. Report exact output path and any checks that could not be completed.
