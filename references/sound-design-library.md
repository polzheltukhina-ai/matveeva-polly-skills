# Sound design and audio library selection

Use this reference only when the user asks for music/SFX or the approved edit plan includes sound design.

## Inventory before choosing

1. Inspect the project's existing audio library and any participant-supplied tracks.
2. Read available metadata: filename, duration, sample rate, channels, loudness/peak where measurable, and any available tags/description.
3. Record source and rights/permission status. If licensing is unknown, mark it unknown; do not assume a sound is royalty-free because it is in a folder.
4. Reuse existing approved files. Do not download or generate replacement audio without user approval.

## Sound categories

| Category | Typical purpose | Example event |
|---|---|---|
| Whoosh | Movement / transition | Swipe, fast push, object travel |
| Impact / Boom | Strong arrival | Main title, result reveal |
| Click / Tick | Small UI or text event | Highlight, toggle, short label |
| Pop | Light appearance | Small card or object entry |
| Riser | Build-up / anticipation | Lead-in to a reveal or CTA |
| Typing | Text entry | Actual typing animation |
| Scroll | Browsing / list movement | Page or asset carousel |
| Tension / Ambient | Emotional bed | Serious or suspenseful beat |
| Glitch | Digital disruption | Only when brief/style explicitly calls for it |
| Ding / Success | Confirmation | Completed action or positive result |

## Placement and mix rules

- Tie every SFX to a visible event and its actual impact/peak frame.
- Avoid repetitive or excessive SFX. Silence is valid sound design.
- Never use a sound merely because the category exists.
- Voice is the priority. Music must sit below speech and be ducked when needed.
- Check clipping, peak levels, loudness, fades, sync, and duration.
- Avoid processing that removes consonants or quiet word endings.
- Keep original voice identity; do not pitch-shift or time-stretch unless requested.
- Re-check the mix after timing edits.
- Do not promise a target LUFS unless the project's export requirements specify one; report measured loudness and true peak when available.

## Music

Choose by the video's tone and pace, not a generic fixed mapping. Start with participant-supplied/licensed library tracks. Confirm permission for commercial/social use before publication. If no suitable cleared track exists, ask whether to proceed without music or use a user-approved source.

## Delivery record

Record selected audio filenames, source/license status, in/out points, gain, ducking, fades, and final measured loudness/true peak in the project plan or QA report.
