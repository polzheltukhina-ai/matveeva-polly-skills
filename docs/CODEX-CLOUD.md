# Codex Cloud: ограничения и настройка

- Codex Cloud работает с выбранным репозиторием и настроенным облачным окружением.
- Репозиторные Skills размещай в поддерживаемой директории, например `.agents/skills/<skill-name>/SKILL.md`.
- Локальная установка Skill на компьютере не означает, что он доступен в Cloud.
- GitHub хранит файлы, но не предоставляет автоматически Node.js, FFmpeg, браузеры, кодеки или платные API.
- Зависимости и команды установки должны быть описаны и проверены в Cloud Environment.
- Не храни API-ключи и секреты в публичном репозитории.
- Убедись, что исходные видео доступны текущей среде, а не только локальному компьютеру.
