# Быстрый старт участницы

## Получить библиотеку
1. Создай аккаунт GitHub.
2. Открой публичный репозиторий Матвеевой Полины.
3. Нажми **Use this template → Create a new repository** (если владелец включил Template repository).
4. Создай собственную копию в своём аккаунте.

## Подключить Codex
1. Подключи GitHub в Codex.
2. Для Codex Desktop клонируй свой репозиторий и открой локальную папку проекта.
3. Для Codex Cloud создай Cloud Environment через веб/Desktop, выбери собственный репозиторий и настрой зависимости.
4. Открой подготовленное облачное окружение в Codex на iPhone.

## Проверить навыки
Попроси Codex: «Прочитай AGENTS.md и SKILL-INDEX.md. Просканируй .agents/skills, перечисли найденные навыки, проверь дополнительные файлы и зависимости. Ничего не изменяй. Отдельно укажи, что реально доступно в текущем окружении».

## Начать монтаж
Загрузи исходное видео, опиши желаемый результат и попроси подготовить таймкодированный план и раскадровку. Запускай финальный рендер после проверки плана.
