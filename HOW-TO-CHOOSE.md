# Как выбирать Skills

1. Определи результат: talking head, монтаж по референсу, субтитры, удаление пауз/оговорок, UI-анимация, рекламный ролик, explainer или другое.
2. Определи формат, платформу и что пользователь хочет сделать с исходной речью: сохранить полностью, убрать паузы, убрать оговорки/повторы, вырезать фрагменты или выбрать дубли.
3. Выбери один основной движок под задачу: Remotion, GSAP/HyperFrames или HTML/Playwright/FFmpeg workflow. Смешивай их только при конкретной технической необходимости.
4. Выбери минимальный набор Skills по таблице в SKILL-INDEX.md. Не подключай режиссуру, раскадровку и QA как ритуальный комплект для каждого простого ролика.
5. Прочитай полный SKILL.md выбранного навыка и только те references, на которые он ссылается для текущей задачи.
6. Проверь только версии и зависимости выбранного движка и нужных эффектов. Полную диагностику окружения делай при первой настройке, после изменения среды или при ошибке.
7. Используй уже сохранённые результаты анализа, транскрипции, монтажные карты и компоненты, если исходники и требования не изменились.
8. Покажи пользователю выбранные Skills и кратко объясни зачем. Не называй каталог источников установленным Skill.
9. Если Skill или зависимость не проверены в текущей среде, явно обозначь это.
10. Для простого talking-head монтажа обычно достаточно навыка выбранного движка и навыка обработки речи, если нужны вырезки. Для монтажа по референсу добавь video-director; storyboard-generator подключай при нескольких сценах или сложной композиции; visual-quality используй для отдельного QA-прохода.
