# Как выбирать Skills

## Полный монтаж Reels

1. Если пользователь загрузил исходник и просит смонтировать Reels, выбери `reels-production-director` как главный управляющий Skill.
2. Он принимает исходник, необязательный референс, дополнительные материалы и брендбук; проверяет доступность файлов; создаёт или продолжает проект и единый `plan.json`.
3. Он проверяет только нужные инструменты и выбирает один основной движок. Для существующего Reels-проекта с рабочей React-композицией сначала рассматривай Remotion.
4. Он использует Faster-Whisper, если он реально установлен и нужен для транскрипции. В Reels-studio предусмотрен `scripts/transcribe.py`; не добавляй Groq по умолчанию. Повторно используй валидные word timestamps.
5. Он подключает специализированные навыки по необходимости: речь, референс, лицо/маски, брендбук, Remotion/HyperFrames, QA.
6. При выборе motion и переходов читай `references/motion-library-selection.md`; при звуковом оформлении — `references/sound-design-library.md`. Не загружай их для задачи, где графика/звук не меняются.
7. Покажи план и спорные решения. Для сложного или непроверенного эффекта сначала сделай короткий proof. Полный рендер выполняй после требуемого согласования.
8. Сохраняй транскрипт, анализ референса, каталог материалов и план в проекте. Не повторяй анализ, если исходники и настройки не менялись.
9. В конце отдельно сообщи автоматические проверки, визуальный просмотр, прослушивание звука и непроверенные пункты.

## Отдельные задачи

- Только субтитры: Skill выбранного движка + готовая транскрипция/word timestamps; не запускай весь монтажный маршрут.
- Только чистка речи: `conversation-editing`; монтажный движок подключай лишь для экспорта.
- Только анализ референса: `reference-fidelity`; не рендери видео.
- Только motion-композиция: Remotion/GSAP/HyperFrames по фактическому проекту и проверенной среде; читай только нужную документацию.
- Повторная правка существующего ролика: `incremental-editing`, переиспользуй plan и валидные промежуточные результаты.

## Выбор движка и ресурсов

- Remotion — default для React-композиций, титров, последовательностей и большинства Reels, если проект уже работает.
- HyperFrames — только при подтверждённом CLI, версии и рабочем примере. Не считай package dependency доказательством готового рендера.
- FFmpeg/Python — поддерживающие инструменты для probe, нарезки, аудио, кодирования, contact sheets и QA.
- Не объединяй движки ради разнообразия.
- Не устанавливай пакеты, модели или внешние API без конкретной причины и согласования.
- Не считай reference-only идею готовым компонентом. Проверяй компонент в текущем проекте.
