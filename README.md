# Библиотека навыков видеомонтажа

Репозиторий содержит только навыки для технической работы с видео: Remotion, GSAP, HyperFrames, motion design, раскадровка, режиссура и контроль качества.

## Использование
1. Создайте копию репозитория через **Use this template → Create a new repository**.
2. Подключите GitHub к Codex и откройте свою копию.
3. Codex использует repo-local Skills из `.agents/skills/`.
4. Перед задачей попросите Codex изучить `SKILL-INDEX.md` и выбрать подходящие навыки.
5. Проверьте зависимости и доступность рендера в текущей среде.

## Что здесь намеренно отсутствует
- мульт-маркетинг и авторские персонажи;
- личные брендбуки и визуальные правила Полины;
- индивидуальные материалы её клиентских и личных проектов.

Участницы используют собственные брендбуки, исходники и визуальные настройки. Эта библиотека отвечает за технические навыки видеопроизводства, а не за единый стиль всех роликов.
