# Библиотека навыков видеомонтажа

Технические навыки Remotion, GSAP, HyperFrames, motion design, режиссуры и QA. Личные брендбуки, исходники и настройки участниц остаются в их проектах.

## Централизованное подключение к проекту Codex

В корне своего монтажного проекта один раз выполните:

```bash
mkdir -p .matveeva-cache
curl -fsSL https://raw.githubusercontent.com/polzheltukhina-ai/matveeva-polly-skills/main/scripts/sync-skills.sh -o .matveeva-cache/sync-skills.sh
bash .matveeva-cache/sync-skills.sh
```

Добавьте /.matveeva-cache/ в .gitignore проекта, не заменяя существующие правила.
Для каждой новой задачи выполняйте bash .matveeva-cache/sync-skills.sh один раз. Если среда новая, повторите первоначальное подключение. Требуются git, bash и сетевой доступ к GitHub. Для закрытого репозитория необходима авторизация и доступ.

Скрипт возвращает LIBRARY и VERSION. Прочитайте AGENTS.md и SKILL-INDEX.md из LIBRARY, затем только выбранные SKILL.md и необходимые подразделы. Не копируйте все навыки в .agents/skills и не считывайте их рекурсивно. Инструкции библиотеки не заменяют инструкции и брендбук проекта.

Если сеть недоступна, существующий кеш используется с предупреждением OFFLINE; при отсутствии кеша сообщите о блокере. Не выдавайте кеш за проверенную актуальную версию.
Для отката: MATVEEVA_PIN=<полный SHA коммита> bash .matveeva-cache/sync-skills.sh. Для следующего обновления уберите MATVEEVA_PIN. Не редактируйте кеш вручную.

## Промпт для новой задачи

Используй Matveeva Polly Skills. Если кеш отсутствует, подключи библиотеку по инструкции выше. Синхронизируй один раз перед задачей. Прочитай AGENTS.md и SKILL-INDEX.md из пути LIBRARY, выбери минимальный набор навыков. Не читай остальные. Сохраняй исходники и настройки моего проекта. Проверь только необходимые зависимости. Сообщи версию и выбранные навыки.

## Старый способ

Копии через Use this template и ранее установленные .agents/skills не обновляются автоматически. Для перехода используйте централизованное подключение и не загружайте дублирующие старые навыки. Не удаляйте пользовательские файлы автоматически.
