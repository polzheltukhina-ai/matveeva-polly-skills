# Storyboard Generator

For each scene provide source timecode, scene purpose, crop/framing, on-screen text, animation, audio, selected skill, and platform safe-zone notes.

Use actual source frames where possible. Generate a contact sheet or visual preview when tools allow. If only a textual plan is possible, state that no visual storyboard image has been rendered.

Do not fabricate frame details or timestamps. For uncertain details, mark them as estimates and request confirmation. Do not start final rendering before approval unless explicitly instructed.
