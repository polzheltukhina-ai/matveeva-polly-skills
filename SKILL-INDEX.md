# Индекс навыков для участниц: видеомонтаж

Библиотека содержит навыки и технические материалы для анализа, подготовки и монтажа видео. Личные брендбуки, исходники и персональные правила оформления конкретного автора остаются в проекте участницы.

## Главный маршрут Reels

| Skill | Для чего нужен | Когда подключать |
|---|---|---|
| reels-production-director | Полный производственный цикл: исходники, референс, материалы, план монтажа, выбор эффектов, исполнение, итерации и QA | Основной вход для монтажа Reels от исходника до MP4 |
| reels-production-brief | Превращает готовый анализ исходника/референса и пожелания автора в полный Reels Production Brief и Codex Execution Prompt | Второй этап после анализа, перед передачей задания в Codex |

Для выбора визуальных решений главный Skill по необходимости читает:
- `references/motion-library-selection.md` — как выбирать motion-компоненты и переходы;
- `references/sound-design-library.md` — как выбирать музыку и SFX;
- `schemas/edit-plan.schema.json` — структура единого плана монтажа.

Эти reference-файлы описывают правила выбора, а не гарантируют наличие конкретного эффекта или аудиофайла в проекте. Наличие и статус компонента проверяются в рабочем проекте.

## Специализированные навыки

reels-production-brief подключается после анализа, использует уже сохранённые результаты и не повторяет транскрибацию или анализ референса.

| Направление | Skill | Для чего нужен | Когда подключать |
|---|---|---|---|
| Монтаж речи | conversation-editing | Транскрибация, удаление согласованных пауз/оговорок/повторов, вырезка фрагментов, edit decision list | Когда нужно редактировать речь |
| Точность референса | reference-fidelity | Перенос конкретных монтажных приёмов без самовольного редизайна | Когда есть референс |
| Сохранение лица | face-preservation | Композиция, безопасный кроп, маски и сохранение лица в кадре | При изменении масштаба, рамки, положения человека или сегментации |
| Визуальные ограничения | visual-constraints | Соблюдение брендбука, must-have и запретов | Когда есть брендбук или строгие визуальные требования |
| Экономное редактирование | incremental-editing | Повторное использование проекта и локальные исправления | При повторных правках |
| Remotion | remotion-best-practices | Создание и рендер видео-композиций на React | Когда выбран Remotion |
| Предпродакшен | storyboard-generator | Подготовка раскадровки | Для нескольких сцен/сложной композиции |
| Режиссура | video-director | Планирование видеопроизводства за пределами стандартного Reels-маршрута | Для самостоятельных сложных видеозадач |
| Контроль качества | visual-quality | Проверка визуального результата | Для финального QA |

## Правила маршрутизации

- Для полного монтажа Reels начинай с `reels-production-director`; он сам подключает только нужные специализированные навыки.
- Для отдельной задачи (например, только субтитры) не запускай полный производственный конвейер.
- Не подключай все навыки сразу. Один проект — один основной движок, если нет конкретной технической причины иначе.
- Remotion — основной маршрут по умолчанию для существующих React-композиций и большинства Reels, если проект уже собирается.
- HyperFrames используй только после проверки CLI, версии и рабочего примера в текущем проекте. Установленный npm-пакет сам по себе не подтверждает рабочий pipeline.
- В Reels-studio для речи предусмотрен Faster-Whisper через `scripts/transcribe.py`. Проверяй фактическое наличие пакета и модели; не добавляй Groq как обязательную зависимость.
- Не запускай транскрибацию повторно, если валидные таймкоды уже есть для того же исходника.
- motion и sound reference читай только когда задача действительно требует выбора графики или звука.
- Компонент со статусом reference-only или untested нельзя выдавать за готовый эффект. Сначала проверить или сделать короткий proof.
- Skill не равен установленной программе. Проверяй только зависимости выбранного маршрута.

## Важные границы

- В библиотеке нет единого обязательного стиля для всех участниц.
- У каждой участницы свой BRAND.md, шрифты, цвета, запреты и дополнительные ассеты.
- Визуальная библиотека гибкая по выбору, но выбор ограничен назначением, совместимостью, качеством исходника и референсом.
- Техническая документация движка не заменяет визуальные требования пользователя.
