# Индекс навыков для участниц: видеомонтаж

Библиотека содержит навыки и технические материалы для анализа, подготовки и монтажа видео. Личные брендбуки и персональные правила оформления конкретного автора сюда не входят: участницы используют собственные визуальные правила.

## Основные навыки

| Направление | Skill | Для чего нужен | Когда подключать |
|---|---|---|---|
| Монтаж речи | conversation-editing | Транскрибация, удаление пауз/оговорок/повторов, вырезка фрагментов, edit decision list | Когда нужно редактировать разговорный исходник |
| Точность референса | reference-fidelity | Перенос конкретных монтажных приёмов без самовольного редизайна | Когда ролик делается по референсу |
| Сохранение лица | face-preservation | Композиция, безопасный кроп, маски и сохранение лица в кадре | Когда меняется масштаб, рамка или положение человека |
| Визуальные ограничения | visual-constraints | Соблюдение брендбука, запретов и утверждённых параметров | Когда есть строгие требования к оформлению |
| Экономное редактирование | incremental-editing | Повторное использование проекта и локальные исправления | Для повторных итераций и всех проектов с готовой базой |
| Remotion | remotion-best-practices | Создание и рендер видео-композиций на React | Когда выбран Remotion |
| Предпродакшен | storyboard-generator | Подготовка раскадровки | Для нескольких сцен/сложной композиции |
| Режиссура | video-director | Планирование видеопроизводства и выбор подхода | Для монтажа по референсу/сложного ролика |
| Контроль качества | visual-quality | Проверка визуального результата | Для финального QA |

## Правила выбора

- Не подключай все навыки сразу. Выбирай минимальный набор по текущему запросу.
- Для простых субтитров используй только Skill выбранного движка; conversation-editing добавляй, если нужно менять речь.
- Для сложного монтажа по референсу обычно нужны reference-fidelity, visual-constraints и Skill движка; video-director/storyboard-generator добавляй по сложности.
- face-preservation нужен при кропе, уменьшении, рамке, маске или foreground separation.
- incremental-editing полезен при повторных правках существующего проекта.
- Один проект — один основной движок, если нет конкретной технической причины иначе.
- Skill не равен установленной программе: перед исполнением проверь нужные зависимости.
- Не помечай навык как протестированный, пока он не прошёл реальную проверку в текущей среде.

## Важные границы

- Здесь нет личного видеобрендбука Полины и её цветовых/шрифтовых правил.
- Участницы применяют собственные брендбуки и визуальные предпочтения.
- Техническая документация движка не заменяет визуальные требования пользователя.
